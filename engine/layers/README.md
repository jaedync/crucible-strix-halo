# engine/layers: charter

Rank 2 (layer operators).

## Interface

- Non-EXL3 operators of the forward pass (`ops.h`): norms, GDN decode, QSA
  decode, HC read and write-back, MoE route, PLE mix.
- Row variants: `gdn_rows.h`, `moe_rows.h`, `moe_chunk_map.h`,
  `dense_rows.h`, `hc_wmma.h`.
- Prefill operators: `prefill_hc.h`, `prefill_ple.h`, `prefill_moe.h`,
  `prefill_moe_pair.h` (M1: gate/up and the mid step in one kernel)
  with its K-set allowlist `prefill_moe_kset.h` (host only).
- Long-context QSA: `qsa_long.h`; capture tool `qsa_capture.h` with its
  policy `qsa_capture_policy.h`.
- MoE helpers: `moe_window_policy.h` (the MoE window compile switch),
  `moe_shared_first.h` (shared-expert-first plan order) and `expert_count.h`
  (measurement: distinct routed experts per MoE call).
- Persistent R=1 prototype: `persistent_gdn.h`, `persistent_hc.h`,
  `persistent_ops.h` (generated by `tools/generate_persistent_ops.py`).
- Debug-build non-finite probes (`nonfinite_probe.h`, an earlier change; the default build
  compiles nothing from it).
- Numerics mode (`numerics.h`), KV storage addresses (`cache_storage.h`),
  descriptor copies (`packed_state.h`), the HC write-back edit
  (`ablation*.h`).
- Device-only kernels live in `kernels/` (see its charter).

## Invariants

- Row r of a multi-row call gives the bits of the R=1 call for row r.
- fp32 GDN state is part of the exactness contract.
- One operator, one host entry. Do not add a layer loop here; the forward
  loops are in `engine.hip` and `runtime/` (structure rules).

## Allowed includes

- `engine/gfx1151/`, `engine/exl3/` (with its kernels), `engine/layers/kernels/`
  and the leaves.
- Two includes of `model.h` (`persistent_gdn.h`, `prefill_moe.h`) are upward
  today. They are in the `tests/test_layering.py` baseline.

## Switches

The registry (`engine/switches.h`) is the truth for the names and the module of each switch.
Names have the prefix `CRUCIBLE_`, left out here.

- Numerics: `HC_WMMA`, `PERSISTENT_GDN`, `PF_EXACT_SPLIT`, `PF_GDN_EAGER`, `PF_GDN_MICRO`, `PF_HC_FUSED`, `PF_QSA_ROWS`.
- Diagnostic: `QSA_CAPTURE_AT`, `QSA_CAPTURE_DIR`, `QSA_CAPTURE_INDEX_ONLY`.
- Build macro: `GDN_VSCAN_MUTANT`, `PERSISTENT_GDN_DEPENDENT_LDS`, `PERSISTENT_GDN_LIMIT_LOADS`, `PERSISTENT_GDN_PREFETCH`, `PERSISTENT_GDN_SERIAL`, `PERSISTENT_GDN_WAVES`, `PERSISTENT_HC_PIPE`, `PF_QSA_SCORE_MODE`, `QSA_POOL_TILED`, `QSA_PREFETCH`, `QSA_SPLITS`, `QSA_TRACE`.
